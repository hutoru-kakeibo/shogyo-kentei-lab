# 商業検定ラボ

商業高校生専門のオンライン検定対策塾のランディングページ。Next.js (App Router) + Tailwind CSS で構築。

開発・引き継ぎに関する詳細は **[HANDOVER.md](HANDOVER.md)** を参照してください。

## Getting Started

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000)（`.claude/launch.json`経由で起動する場合はポート3010）で確認できます。

## コマンド

```bash
npm run dev     # 開発サーバー
npm run build   # 本番ビルド
npm run start   # 本番ビルド起動
npm run lint    # ESLint
```
